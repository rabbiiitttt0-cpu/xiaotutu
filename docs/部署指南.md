# 部署指南

看图兔支持三种部署方式：**Docker Compose（推荐，生产）**、**本地开发**、**裸机（不用 Docker）**。

---

## 一、部署前准备

### 硬件要求

| 场景 | 最低配置 | 说明 |
|---|---|---|
| 试用 / 小团队（<10 人） | 2 核 4G | 官方演示环境即 2C4G；`docker-compose.yml` 中 app 内存上限 3g |
| 中等团队 / 大图较多 | 4 核 8G | 单张几十 MB 的装修/暖通大图渲染需要更多内存，否则会触发 15 分钟超时保护 |
| 数据盘 | ≥ 20G | 图纸原文件 + 渲染图 + 切片，按图纸量增长 |

### 软件要求

- Docker 24+ 与 Docker Compose v2
- 开放端口：**80**（nginx，必须）；443（可选，配 HTTPS 用）
- 国内服务器建议先配 Docker registry mirror，加速镜像拉取

## 二、Docker Compose 部署（生产推荐）

```bash
# 1. 获取代码
git clone https://github.com/rabbiiitttt0-cpu/xiaotutu.git
cd xiaotutu

# 2. 配置环境变量
cp .env.example .env
```

编辑 `.env`：

```ini
IMAGE_TAG=v1.0.0

# 生产用 PostgreSQL（compose 自带 db 服务，留空则 SQLite 兜底）
DATABASE_URL=postgresql+psycopg2://xiaotutu:你的强密码@db:5432/xiaotutu

POSTGRES_USER=xiaotutu
POSTGRES_PASSWORD=改成随机强密码
POSTGRES_DB=xiaotutu
```

```bash
# 3. 构建并启动
docker compose -p xiaotutu build
docker compose -p xiaotutu up -d

# 4. 健康检查（冷启动导入 onnxruntime/opencv 较慢，最长等 2 分钟）
curl http://127.0.0.1/api/health
# 期望返回 {"status":"ok",...}
```

启动后浏览器访问 `http://服务器IP/`，默认超管 **`admin / admin123`**。

> ⚠️ **第一件事：登录后立即修改默认密码**（侧栏底部「修改密码」）。`admin123` 是源码公开的初始密码，不改等于裸奔。

### 容器构成

| 容器 | 作用 | 内存上限 |
|---|---|---|
| `xiaotutu-nginx` | 反代 + 静态前端，对外 80/443 | 默认 |
| `xiaotutu-app` | FastAPI 后端 + 预处理队列（双 worker） | 3g |
| `xiaotutu-db` | PostgreSQL 16（仅内网，不对外） | 512m |

### 升级

```bash
cd xiaotutu
git pull                      # 或上传新版本代码
docker compose -p xiaotutu build
docker compose -p xiaotutu up -d
```

升级前建议备份 `data/` 目录（见下文「备份」）。维护者也可用 `deploy/deploy.sh`（约定从 `/tmp/bundle_xiaotutu.tar.gz` 解包，会自动保留旧 `.env` 并做健康检查，失败自动回滚）。

### 备份

```bash
# 数据全在 data/ 目录：SQLite/PG挂载点、图纸、LLM配置
tar czf xiaotutu_backup_$(date +%F).tar.gz data/ pgdata/ .env
```

恢复：停服 → 解压回原位 → 启动。

## 三、本地开发

要求 Python 3.12+、Node 18+。

```bash
# 后端（端口 7780；Windows 设 PYTHONIOENCODING=utf-8）
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 7780

# PC 前端（端口 5173）
cd frontend-pc && npm install && npm run dev

# 移动前端（端口 5174，已 proxy 到 7780）
cd frontend-mobile && npm install && npm run dev
```

访问 `http://127.0.0.1:7780/`（PC）/ `http://127.0.0.1:7780/m/`（移动端模拟）。
本地开发不填 `DATABASE_URL`，自动用 SQLite（`data/app.db`），零配置。

## 四、配置 LLM（部署后必做）

1. 用超管登录 → 侧栏「系统设置」→ LLM Provider 页
2. 添加一个**支持多模态视觉**的模型（如 DeepSeek-VL 系列、Qwen-VL、GPT-4o 等，OpenAI 兼容接口），填入 API Key 与模型名
3. 配置存于 `data/app_config.json`（已 gitignore），**备份时不要漏掉它**

看图兔的问答质量取决于视觉模型能力；key 只存在服务器本地，不经过任何第三方。

## 五、可选：域名与 HTTPS

`nginx.conf` 已预留 443 与 `data/letsencrypt` 挂载。国内 ECS 用域名需先 ICP 备案，之后可用 certbot 签免费证书：

```bash
docker run -it --rm -v $PWD/data/letsencrypt:/etc/letsencrypt \
  certbot/certbot certonly --standalone -d your-domain.com
```

然后在 `nginx.conf` 中打开 443 server 块（模板已有注释指引）。
