# 使用说明

## 一、账号与角色

| 角色 | 权限 |
|---|---|
| **超级管理员** | 全部功能：用户管理、项目管理、图纸上传/删除/预处理监控、图纸集维护、系统设置（LLM 配置）、审计日志 |
| **普通用户** | 注册后需超管审批；被加入项目后可见该项目「近期常用」图纸、提问、看自己的历史会话 |

默认超管 `admin / admin123`，**首次登录请立即改密**。

---

## 二、核心使用流程（管理员视角）

```
建项目 → 加成员 → 上传图纸(zip) → 等预处理"就绪" → 打开"近期常用"开关 → 成员即可问答
```

1. **建项目**：超管「项目管理」→ 新建项目（如"XX产业园三期"）
2. **加成员**：项目抽屉「项目成员」Tab → 添加已注册（已审批）的用户
3. **上传图纸**：项目抽屉「图纸管理」→ 上传图纸压缩包（.zip，内含 .dwg/.dxf/.pdf，按目录打包，**上传后保留文件夹层级**）
4. **等待预处理**：后台串行队列自动转换/解析/渲染/切图框，状态从「处理中」→「就绪」。大图纸（>50MB 或几千个图框）可能要几分钟到十几分钟，可离开页面稍后回来
5. **放给成员看**：每张就绪图纸右侧的开关 = 「近期常用」。打开后成员才能在图纸列表看到；排序也是常用置顶
6. **组图纸集**（可选）：「图纸管理」底部的图纸集区，把一套相关图纸（如"桩基一套"）编成组，成员端可一键整套载入，一次提问自动在多图间路由找答案

## 三、成员视角：识图问答

1. 进入「识图助手」→ 选项目 → 选图纸（单张）或图纸集（整套）
2. 输入问题，例如：
   - "这栋楼基础埋深多少？"
   - "二层给排水用的什么管材？"
   - "帮我提取这张图纸的材料表"
3. 辅助功能：
   - **框选提问**：在图上框一块区域，只针对局部问（如"这个节点大样什么意思"）
   - **图纸集模式**：>3 张时自动路由选图，答案注明出自哪张
   - **材料提取 / 快速交底**：一键生成清单/交底文档
4. 会话保留 5 天，可回看历史
5. **手机端**：浏览器直接访问同一地址（`http://服务器/m/` 或自动跳转），现场看图+语音/文字提问

## 四、图纸脱敏（自动）

- 图纸里的**单位名、人名**送 AI 前自动替换为 `【单位1】`【人名2】` 等密文，AI 全程只看密文
- 回答展示时按权限还原：管理员看真名，普通成员保持密文
- 对照表按项目维护（`data/projects/{id}/cipher_map.json`），增量累积，可随时人工编辑修正误报

> 适合图纸要外发审查、又怕泄漏建设/设计单位信息的场景。

## 五、常见问题场景速查

| 你想要 | 怎么做 |
|---|---|
| 一张图问了多次想重来 | 新建会话（会话按 5 天保留） |
| 大图看不清标注 | 打开高清模式（_hi.png 自动用于大图纸）；局部用框选提问 |
| PDF 是扫描件没文字层 | 自动 OCR 补文字层（`drawing_ocr_dpi` 可在系统设置调） |
| DWG 传上去转失败 | 用 CAD 另存为 **DXF（R2013 格式）** 再传，成功率最高 |
| 想把某些图藏起来不给成员看 | 关掉该图的「近期常用」开关（成员列表只显示打开的图） |
| 语音输入按钮没反应 | 见《常见问题》——浏览器限制，推荐文字输入 |

## 六、系统设置（超管）

- **LLM Provider**：配置视觉模型 key（多槽位：绘画/问答可分模型）；key 脱敏展示
- **识别参数**：分块渲染开关、PDF 最大页数、OCR DPI、文字上限等
- **审计日志**：LLM 调用记录、错误日志、用量统计、用户登录历史
